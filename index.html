Features

Everything you need

All templates become actions
Every Live Template from every group appears in Settings → Keymap under "Live Template Shortcuts".
Standard Keymap integration
Assign shortcuts exactly like any other IDE action — with full conflict detection built in.
Dynamic registration
Templates added during a session appear in Keymap immediately, without an IDE restart.
Filter per group
Hide entire template groups from the Keymap list via Settings → Editor → Shortplate.
Non-destructive
Previously assigned shortcuts remain active even if a template is later hidden in the filter.
Works everywhere
Compatible with all JetBrains IDEs — IntelliJ IDEA, Rider, WebStorm, PyCharm, and more.
Installation

Up and running in 2 minutes

1
Open Plugin Settings
In any JetBrains IDE, go to Settings → Plugins → Marketplace.
2
Search for Shortplate
Type "Shortplate" and click Install, then restart your IDE.
3
Open Settings → Keymap
Expand Plugins → Shortplate → Live Template Shortcuts.
4
Assign your shortcuts
Find the template you want, double-click it, and press your desired key combination.
